# How to do stuff in nexomaker! 
this is just a collection of stuff that being a member of the nexomaker community has taught me to learn and now for me to share to you reading this. So you dont have to keep asking the same question over and over again!


# FaQ

<details>
<summary>What do I need before starting?</summary>

You need a [NexoMaker](https://nexomaker.com/) account, a verified email, and the desktop client installed. Make sure your client is updated to the latest version so you have access to all the latest features!. You will also need one of 3 plugins [Nexo](https://nexomc.com/)(paid), [ItemAdder](https://www.spigotmc.org/resources/%E2%9C%A8itemsadder%E2%AD%90emotes-mobs-items-armors-hud-gui-emojis-blocks-wings-hats-liquids.73355/)(paid), or [CraftEngine](https://modrinth.com/plugin/craftengine) (free)

> **Note** NexoMaker is a paid software with a free tier that has some limitations. You can check out the [pricing page](https://nexomaker.com/premium) for more information. 

> **Note** NexoMaker works best with Nexo and ItemAdder as they have offical support. CraftEngine is not offically supported but can still be used with some extra steps.

</details>

<details>
<summary>How to get started?</summary>

Open NexoMaker and log in. Click on "New Project" to create a new project. Choose a project base (you will see only two options Nexo & Itemadder) Choose which one you have and click "Create". You can now start building your project using the various tools and features available in NexoMaker. 

</details>

<details>
<summary>You said craftengine works with extra steps? What are those extra steps?</summary>

As CraftEngine **does not** have **offical support**. However you can still use craftengine by first creating a project and going to the NexoMaker Marketplace and get the craftengine extension that adds craftengine support. Then adding craftengine as a plugin in the server environment settings.

> **Note** Some features may not work as expected due to the lack of offical support. The extention is opensource so if you find any issues you can report them on the [GitHub repo](https://github.com/dodi2020/NM-CraftEngine-Expansion) Or make pull requests to fix them yourself if you know how to code.

</details>

<details>
<summary>How to add plugins to NexoMaker Server Environment</summary>

Nexomaker has a server environment feature that allows you to add plugins to your project for testing purposes. To add plugins, follow these steps:
1. Open your project in NexoMaker.
2. Click on "test changes in local server" button. (it looks like a `[>]` icon )
3. Click start and wait for the server to download then click stop. goto the settings on the right where it says `PLUGINS` then click add plugin.

> **Note** You are able to add more plguins with the [paid version of NexoMaker](https://nexomaker.com/premium) you get 2 plugins on the free tier.

4. Browse and select the plugin file you want to add (make sure its a .jar)
</details>


<details>
<summary>How do I share/export my project?</summary>

Go to **project settings > Export > Format** You can export in differnt formats but this may remove some features that dont work in some formats. Its best to export to the format of the project you choose when creating the project. (Nexo or ItemAdder or CraftEngine) then click export and choose where to save it.
</details>
